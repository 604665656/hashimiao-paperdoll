## 写法约定

每条新记录包含四段，缺一段就算没写：

1. **要解决什么** —— 一句话，别写背景故事
2. **怎么做的** —— 关键决策和取舍，不写代码细节
3. **验证** —— 跑了什么、数字是多少。没验证就写「未验证」
4. **坑** —— 踩过的、下次别再踩的

新增一天：复制 `模板.md` 改名成 `YYYY-MM-DD.md`，然后在上面索引表加一行。
同一天多次改动直接往下追加，标时间。
