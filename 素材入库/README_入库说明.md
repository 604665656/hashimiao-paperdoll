# 截图批量入库 · 用法

把你**自己获取**的整屏截图或精灵表，一次处理成可直接使用的单只素材。
不下载、不搬运第三方素材库，只处理你丢进 `_inbox` 的图。

## 三步

1. 截图，丢进 `素材入库/_inbox/`（png / jpg 都行，可以一次丢几十张）
2. 双击 `tools/入库.bat`
3. 去 `素材入库/out/` 取货

## 产物

| 文件 | 内容 |
|---|---|
| `哈士喵_01.png …` | 单只素材，已去背、已裁到内容边界 |
| `index.json` | 每个素材的来源图、原始坐标 `box`、裁后尺寸、像素面积、统一画布尺寸 |
| `_总览.png` | 一页看完所有结果，带文件名，先扫这张验收 |

## 两种切法

**A. 自动切（默认）**
适合整屏截图里散落多只的情况。做法：取四角颜色当中位数估计背景 → 颜色差超过容差算前景 → 膨胀合并同一只的碎块 → 连通域切图 → 按行优先排序。

```bash
python tools/截图入库.py
python tools/截图入库.py --tol 34          # 背景不干净 / JPEG 噪点多，调大容差
python tools/截图入库.py --min-area 1200   # 只留大件，过滤小碎块
python tools/截图入库.py --no-normalize    # 不做统一画布，保留原始尺寸
```

**B. 网格切（已知行列）**
适合精灵表。每格内部再做一次自动切，所以格子留白多也不会切歪，也不会串到隔壁帧。

```bash
# 8 列 = 8 个方向，4 行 = 4 帧 → 自动命名 哈士喵_E_p2.png 这种
python tools/截图入库.py --grid 8x4 --dirs N,NE,E,SE,S,SW,W,NW --prefix 哈士喵

# 4 列 4 行，行列反过来也行（列=帧，行=方向）
python tools/截图入库.py --grid 4x8 --dirs N,NE,E,SE,S,SW,W,NW
```

命名规则：
- 列数 = `--dirs` 个数 → 列是方向，行是帧 → `前缀_方向_p帧.png`
- 行数 = `--dirs` 个数 → 行是方向，列是帧 → 同上
- 都不是 → `前缀_r行c列.png`

## 归一化规则

默认把所有素材贴到同一块画布上：**底边对齐、水平居中**，画布尺寸 = 最大素材尺寸。
这样切出来的东西能直接按同一锚点叠到骨骼位上，不用挨个对偏移。`index.json` 里的 `normalized_canvas` 就是这块画布的尺寸。

## 常见问题

| 现象 | 处理 |
|---|---|
| 切出大量碎块 | `--min-area` 调大；`--merge-gap 4` 让同一只的碎块更容易合并 |
| 边缘残留背景色 | `--tol` 调大（28→40）；JPEG 截图建议先转 PNG |
| 两只粘在一起 | `--merge-gap 1`，或改用网格切 |
| 半透明特效被切掉 | `--tol` 调小（12左右），否则淡色特效会被当背景 |
| 切出来顺序乱 | 自动切按「行优先」排，行高容差取中位高度的一半；行距特别不齐时用网格切 |

## 接进纸娃娃台

切好的图按 `素材入库/out/` 里的文件名直接丢进：

- 部件层：`assets/单源版/01_骨架层/`（保持 1328×1776 同画布才能零偏移叠加）
- 配饰：`assets/单源版/02_配饰层/<角色名>/`，再去 `js/parts.js` 的 `suits` 里加一条
- 八向帧：`assets/八向资产/03_裁切帧/`，按 `N_p1_板1.png` 命名

尺寸不一致时，用 `--no-normalize` 看过原尺寸，再统一缩放到目标画布。
