# 8 向参考层 → 厚涂候选 → 导演台（本轮「继续」做了什么）

> 上一轮停在「参考层 8/8 齐、资产层 1/8」，给了三选一。这轮按 **A（补生成厚涂 8 向动作帧）+ C（接进网页按 rect 播帧并叠换装）** 一起做，**没有再问**。结论前置：**生成没达标，不冒充 8 向资产**。

## 一、先说结果

| 层 | 上一轮 | 本轮 |
|---|---|---|
| 参考层（3D 白模） | 8/8，412 帧 | 不变 |
| 候选层（厚涂生成帧） | 无 | **4/8，16 帧，全部 `status=candidate`** |
| 资产层（可装配） | 1/8，64 帧 N | **仍 1/8，一帧没转正** |

**为什么没转正**：4 张拼板 32 帧里，绿残留 0 / 多手 0 / alpha 洞 0 / 孤立域 0，两个老硬伤治住了；但**目视复核只有「正面 / 背面 / 朝右走路」3 类**，30/32 帧与 prompt 声称的方向不符。板2~4 是同一姿态的重复（轮廓 Hu 距离 0.11~0.18），上下排也没镜像；画风还分两套——板1 灰白厚涂（图生图，传了身份锚），板2~4 暖黄淡彩（文生图，因为单次请求输入图额度用满）。

按你定的「批量出候选 → 人眼挑 → 工程化」，这批就只能停在候选区。

## 二、生成怎么排的（效率优先，沿用你定的分镜先行）

- **先定分镜**：8 向 × 4 走路相位（并脚 / 迈左腿 / 交错 / 迈右腿）= 32 格，写死成 4 张板、每板 4×2=8 格（上排一个方向、下排一个方向）
- **一次出板再裁**：4 次生成 → 4 张 2048×1152 纯米底拼板 → 自适应前景检测裁 32 帧，不是逐帧跑 32 次
- **输入**：`00_生成输入/身份锚_厚涂Q版纯素体.png`（历史 `q_bare_bald` 贴米底）＋ 4 张「方向姿态卡」（两方向白模 r2c2 左右并排）
- **不用绿幕**：全板绿占比 0.00000，从源头避开「绿色特别多」
- **人形纯素体**：2 手 2 脚，光头无五官无耳无角无尾，从结构上消除「多手 = 前爪+后脚」

板1 走图生图（身份锚 + 正/背姿态卡）成功；板2~4 改走文生图同 seed=5。**这是画风漂移的直接原因，已如实记进报告**，不是模型能力定论。

## 三、做了什么工程补救（都是正当处理，不是掩盖）

| 处理 | 依据 | 结果 |
|---|---|---|
| 毛色归一化 | 你要求「毛色可以替换」 | 板2~4 前景 RGB 按逐通道增益映射到板1 `[216,203,189]`，4 向色差降到 **0.5~1.44**，保留笔触明暗 |
| E 水平镜像补 W | 等距变换，不是你否掉的拉动 / 形变 | 逐像素核验 `E.flip == W` 最大差 **0**；manifest 如实标 `method='E 水平镜像'`，不冒充独立绘制 |
| 只挑可用子集 | 不塞重复帧充数 | N/S 取板1，E 取板2 归一化，W 由 E 镜像 → **16 帧**；板3/4 重复帧与 4 个斜向全部不进表 |
| 精灵表留空 | 缺口可视化 | 8 列 × 4 行，`NE/SE/SW/NW` 四列透明空格，网页写「未生成」 |

**相位差异量化**：侧面走路 E/W 是 0.1015（真迈腿），板1 正/背 N 0.0369 / S 0.0522（几乎静止，已写进报告）。

## 五、从失败里得到的下一轮改法（具体，不是空话）

1. **一张板只画一个方向**：这轮每板塞 2 个方向，模型把两排都画成同一姿态 → 改成 8 板 × 1 方向 × 4 相位，每板只传一张该方向的姿态卡。
2. **8 板全走图生图**：都传同一张厚涂身份锚，别因额度改文生图。
3. **正/背要补区分信号**：光头无五官时正背几乎一样，姿态卡里保留耳突与肩背线，或允许素体带极淡背部中线。
4. **额度说明**：单次请求最多消费 10 张输入图，本轮 4 次失败调用 + 1 次成功重试已用满 10 张，所以板2~4 改文生图。下一轮预留额度，8 板都走图生图。

## 六、如实说的限制

1. **NE / SE / SW / NW 本轮 0 帧**，不是「画了没挑」，是模型根本没画出来。
2. **W 是镜像**，不是独立绘制；左右对称部件（耳突、描边高光）会跟着翻，严格设定稿仍需原画补画。
3. Hu 矩方向判读（`候选自检.json` 里 `measured_dir`）对无五官光头角色不敏感，**只作相对参考**，结论以 `02_预览/32帧_声称vs实测方向.png` 目视为准。
4. 16 帧全是候选，**没人眼挑过就不转正**；主 `manifest.json` 只新增 `candidates` 段与 `gaps.candidate_coverage`，**64 个资产帧的 `direction` 仍是 `N`，一个没改**。
5. 换装叠加页在斜向/背面会把正面五官钉在脸上，**那个页是用来照穿帮的**，不是交付装配；要逐帧对齐得给每个姿态单独定锚点。
6. 仍是整图序列帧，不是 PSD/ORA 分层，做不到骨骼级「只动眼不动手」。
7. 13 张白模与 8 张用户参考图版权来源不明，只作姿态/结构比对，不进 `dist/`、不作图生图底图、不对外发布。
