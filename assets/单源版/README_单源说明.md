# 眼镜猫 · 单源版（推倒重来）

## 你指出的两处，都是我的结构性错误

**嘴巴怪**：上一版「重拆版」的鼻子来自真原型骨架，嘴却来自旧银时母版的生成变体椭圆层。两个源的猫比例、五官位置不同，嘴自然对不上鼻子，看着像错位或重影。

**配件和手变形**：上一版用了三个不同来源硬拼——
- 骨架：真原型三视图正面裁切
- 配饰：从旧 7 张生成立绘里按颜色提取（那些立绘的手和道具本身就是画坏的）
- 表情：从旧银时母版的生成变体里裁椭圆

三套坐标一叠，镜片里出现重影、刀和团子错位、两套手叠影、衣服矩形硬边。我上一轮只验了「回叠 alpha 差 0」，**没验同源**，等于只检查了图层能不能拼回去，没检查拼的是不是同一只猫。判断错了。

## 这版怎么改：只认一个源

唯一像素源 = 你确认的「眼镜猫·角色三视图」正面。

1. 以真原型正面为底图，让模型**只加两件配饰**（头顶假发 + 躯干衣身），不动其他任何东西。
2. 生成完不算完——用**硬保护遮罩**把脸、眼镜镜腿、鼻、嘴、两只前爪、双脚、尾巴、背景、投影**逐像素强制换回原图**。
3. 只放行头顶与躯干两块区域里「生成图非背景」的像素，边界羽化。

所以这次不是拼接，是「原图 + 局部覆盖」。脸和手根本没参与生成结果的取用。

## 明确作废

`重拆版/` 里这两样**不再交付、请不要用**：
- `02_配饰层/`（7 套颜色提取拼贴）
- `04_表情层/`（旧银时变体椭圆）

`重拆版/01_骨架层/` 是干净的，已原样搬进本版。

## 这版只有 2 套，是故意的

先出神乐（红）和土方（黑）两张验方向，一浅一深能看出衣身边界处理。没铺全套，避免又整批跑偏。

## 如实说的限制

- 衣身只覆盖躯干中间一块，没有袖子、没有手持道具。手是骨架的白爪，从衣身两侧自然露出，视觉上偏「围兜」。这是为了不再碰坏手和道具区。
- 假发下缘在额前是平直收口（头顶允许区下缘），不是自然碎发垂落；要更自然得把允许区做成沿额头的弧线。
- 镜腿端点、左手边界还有几百像素的羽化残差，正常尺寸看不出，放大能察觉。
- 表情层这次没做。上一版的表情被作废后，眨眼与口型暂时只能靠 `Live2D参数表.json` 的网格变形；要重新做替换层，必须同样以真原型正面为源生成，不能再用旧变体。

方向对了再铺剩下 5 套，并把表情层按同一个单源规则补齐。
