# 结构参考卡 · 用途与读法

两张卡都是**原创绘制 / 从哈士喵自有素材提取**，不含任何第三方 IP 素材。
用途：给 img2img 或手绘提供一个「结构约束」而不是「现成画」。

## 90_结构参考_比例与衣褶.png

| 区块 | 内容 | 怎么用 |
|---|---|---|
| A 头身比 | 3 / 4 / 6 头身三档，左轴标头身刻度，脚下标头高基准 | 定哈士喵当前是几头身，换装/换角度时锁死头高不变，比例就不会飘 |
| B 衣褶四型 | 管状褶 / 之字褶 / 放射褶 / 悬垂褶 各一张示意 | 生成衣服时在提示词里点名褶皱类型，比写"详细衣服"稳定得多 |
| C 重心 | 站直 / S 形 / 走姿，画了重心线、动态线、支撑面 | 动作帧站不稳时对照：重心线有没有落在支撑面内 |

## 91_八向骨架比例卡.png

从 `assets/八向资产/03_裁切帧` 的 p1 帧提取剪影，统一拉到 400px 高，叠加中轴与十等分刻度。

- **剪影**：只保外形，不带五官配色，喂给 img2img 不会把原画"抄"进结果
- **中轴红线**：检查左右是否歪；斜向帧看头身是否整体偏移
- **十等分刻度**：跨方向比对用。同一角色八向应该是同一套刻度，耳朵高度、下巴位置、膝高在各方向应当基本对齐
- **底部数值**：源帧尺寸与宽高比。NE/NW 明显窄于 N 是正常的（透视），但差太多说明这一板生成时角度飘了

`91_八向骨架比例卡.json` 存了八向的宽高比，可当一致性阈值用：任意两向宽高比差超过 0.12 就该重生成。

## 重新生成

```bash
python tools/参考卡生成.py     # 或双击 tools/生成参考卡.bat
```

改了八向帧（增删方向、换图）就重跑一次，`91` 会自动跟着更新。

## 为什么不用游戏原图直接当参考

外人家的美术资源是别人的版权作品。直接进参考库有两个实际风险：

1. 生成物会带明显 IP 特征，容易撞脸，商用不可用
2. 一旦要公开或交付，素材来源无法说明

用"自己的剪影 + 通用结构规则"这套，能拿到同样的结构约束，但没有来源问题。
