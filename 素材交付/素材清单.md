# 哈士喵 素材清单（交这批就能全功能跑起来）

现有能用的：11 层骨架（1328×1776 同画布）、神乐/土方两套配饰、8 向 × 4 帧。
还缺的都在下面，按优先级排。**P0 不做完，表情和换装是残的。**

## 铁律（不满足就白做）

| 项 | 要求 | 为什么 |
|---|---|---|
| 画布 | 表情/配饰层一律 **1328×1776**，跟 `L00~L10` 完全同一坐标系 | 工具靠零偏移叠加，尺寸一不一样就得手工对位 |
| 裁切 | **不许裁到内容边界**，保留整块画布 | 裁了就丢锚点，八向和眼球都对不上 |
| 格式 | PNG-24 带 alpha，透明背景 | JPEG 会出白边，工具去背会啃掉毛边 |
| 底纹 | **不要纸纹/米色底**，必须抠干净 | 现有拼版图都有底纹，直接切会带脏边 |
| 缩放 | 不要缩放，按原始分辨率交 | 缩放会让像素边缘发糊，厚涂风反而好一点，但别混用不同倍率 |
| 命名 | 严格按下面表格 | `tools/素材体检.py` 按这个名字查缺口 |

## P0-1　表情分件（最重要）

把「8 种表情」拆成 **眼 × 嘴** 两个维度，组合出 30 种，工具里两个下拉就能切。
两边眼睛对称，合成一张即可，不用左右拆。

**`素材交付/01_表情_眼/`** 5 张，1328×1776 透明，位置与 `L04/L05` 完全重合：

| 文件名 | 内容 | 对应你现有的 |
|---|---|---|
| `E1_平静.png` | 圆睁、瞳孔居中 | 已有（L04+L05 现成，可直接拷一份） |
| `E2_眨眼.png` | 单眼半闭或双眼半闭 | 「眨眼」那张 |
| `E3_笑眼.png` | 弯月形，下眼睑上推 | 「笑」「笑+张嘴」共用 |
| `E4_闭眼.png` | 完全闭合，一条弧线 | 「闭眼闭嘴」 |
| `E5_惊讶.png` | 瞳孔放大、眼白多 | 「惊讶圆嘴」 |

**`素材交付/02_表情_嘴/`** 6 张，同样画布，位置与 `L03` 完全重合：

| 文件名 | 内容 |
|---|---|
| `M1_闭嘴.png` | 一条小弧，无开口 |
| `M2_微笑.png` | 小圆口，不露齿 |
| `M3_张嘴.png` | 椭圆开口，露舌 |
| `M4_大笑.png` | 张大、露上颚 |
| `M5_惊讶圆嘴.png` | 竖椭圆 O |
| `M6_吐舌.png` | 舌头伸出 |

> 组合关系（现有 8 张拼版就能对上）：平静=E1+M1，眨眼=E2+M1，笑=E3+M3，张嘴=E1+M3，
> 惊讶=E5+M5，闭嘴=E1+M1（弧度更小），笑+张嘴=E3+M4，闭眼闭嘴=E4+M1。

## 交完怎么验

```bash
python tools/素材体检.py          # 出 素材交付/体检报告.md：缺哪些、尺寸对不对、有没有透明通道
python tools/素材体检.py --install # 体检通过的直接拷进 assets/单源版/03_表情层/ 和 02_配饰层/
```

体检只报不猜：尺寸不对、没抠透明、文件名不匹配，都会单独列出来，不会静默跳过。

## 如果只能先交一部分

1. `E1~E5` + `M1~M6` → 表情下拉能用了（30 种组合）
2. `银时.png` → 换装多一套
3. `木牌.png` + `手_举起.png` → 举牌动作
4. 八向帧扩展 → 动作更顺
